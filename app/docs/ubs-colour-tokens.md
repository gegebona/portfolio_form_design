# UBS colour tokens (reference)

All colour tokens ubs.com publishes as `--col-*`, light-theme values, read on 2026-10-10.
The app's theme ([src/styles/theme.css](../src/styles/theme.css)) contains only the ones it uses (marked ✓).
To use another one, copy its line into theme.css as `--color-ubs-<name>` and point a semantic token at it.
